# AI PickGold Codex Tutorial

![AI PickGold banner](assets/personal-ip/x-banner-1500x500.png)

我是 **智辰老师**，一个 AI 知识博主。我会持续公开拆解 Codex、AI 内容生产、开源仓库、短视频、小红书封面和个人 IP 变现工作流。

这个仓库不是“资料收藏夹”，而是一套面向中文开发者和独立创作者的 **Codex 实战课程**：从桌面端 App、CLI、IDE、Cloud、AGENTS.md、Skills、MCP、GitHub 自动化，一直讲到如何把 AI 工作流变成教程、封面、视频和可复用资产。

## 我怎么建议你学

不要从“收藏 60 篇文章”开始。按这个顺序做：

1. 用一个无敏感信息的小项目跑通 Codex。
2. 写一份 `AGENTS.md`，让 Codex 先理解项目边界。
3. 完成一个小改动，并要求 Codex 给出 diff、验证命令和风险。
4. 把重复任务沉淀成 Skill 或固定提示词。
5. 把一次学习变成教程、封面、短视频和 GitHub 记录。
