# AI PickGold Codex Tutorial

面向中文开发者和独立创作者的 Codex 学习仓库。目标是把 Codex 从“会聊天的代码助手”变成一套可以接管项目、沉淀上下文、生成教程、辅助发布的工作流。

Live site target: https://codex.aipickgold.com

## 学习路线

1. Codex 是什么：App、CLI、IDE、Web / Cloud 的使用边界。
2. 30 分钟上手：登录、打开项目、只读扫描、完成第一个小改动。
3. 项目上下文：README、AGENTS.md、测试命令、目录边界。
4. 安全执行：权限、沙盒、密钥、人工确认。
5. Skills：把重复任务变成可复用能力。
6. GitHub 自动化：Issue、PR、CI 和 Codex Action。
7. 创作者工作流：把教程变成公众号、小红书卡片、视频脚本和发布包。

## 复用边界

这个仓库采用“公开事实源 + 原创改写”的方式建设。

- 官方仓库作为事实源，按其 license 标注使用。
- 用户明确允许公开展示的非敏感仓库，可以进入公开来源清单。
- 未声明 license 的仓库和闭源网站不进入公开来源清单，不搬运代码和文案。
