# Sandbox、权限与安全边界

Codex 真正能落地，靠的不是“胆子大”，而是边界清楚。我的原则是：让 AI 做可验证的事，让人确认高风险动作。

## 三类边界

| 边界 | 例子 | 处理方式 |
| --- | --- | --- |
| 文件边界 | 哪些目录能改 | 写进 AGENTS.md |
| 命令边界 | 哪些命令能跑 | 用权限规则限制 |
| 业务边界 | 发布、支付、账号 | 保持人工确认 |

## 不要交给 Codex 的内容

- 明文 token、cookie、SSH key。
- 生产数据库密码。
- 未脱敏客户数据。
- 账号发布最终点击。
- 付费开通、扣费确认。

## 安全提示词

```text
在开始前，请先列出你可能需要访问的文件、命令和外部服务。
如果需要密钥、生产账号、付费动作或敏感数据，请停止并说明原因。
```

## 公开内容规则

公开 README、教程、网站、截图里，不写：

- 私密研究对象。
- 内部采集目标。
- 部署密钥和服务器细节。
- 未经确认可公开的来源。

这不是保守，而是长期做个人 IP 的基本卫生。
