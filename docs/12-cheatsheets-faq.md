# 速查与 FAQ

## 常用提示词

### 只读扫描

```text
请只读扫描当前项目，列出技术栈、目录结构、启动命令、测试命令和风险点。不要修改文件。
```

### 小范围实现

```text
请只修改与这个任务直接相关的文件。完成后说明 diff、验证命令和剩余风险。
```

### 前端验收

```text
请检查 390px、768px、1440px 三个宽度，确认没有横向溢出、文字遮挡、图片加载失败或 CTA 被挡住。
```

### 公开内容检查

```text
请扫描公开文件，确认没有密钥、内部来源、采集目标、私密路径或不应公开的策略。
```

## FAQ

### Codex 会不会直接替我做所有事？

不会，也不应该。Codex 适合执行可验证任务，不适合替代你的判断。

### 新手先学 CLI 还是 App？

我建议先学 App。理解项目、diff、多线程和本地预览后，再学 CLI 自动化。

### AGENTS.md 有必要吗？

非常有必要。它能让 Codex 每次进项目时都按同一套规则工作。

### Skills 什么时候学？

当你发现一个流程重复做三次以上，就可以考虑做成 Skill。

### 如何避免 AI 乱改？

任务写小、边界写清、先只读、再修改、最后验证。
