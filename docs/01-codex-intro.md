# Codex 是什么

Codex 是 OpenAI 面向软件开发的 coding agent。它可以读取项目、理解上下文、运行命令、修改文件，并把结果交给你 review。

对中文开发者来说，最关键的不是“让 AI 写代码”，而是建立一套可重复的工作流：

- 让 Codex 先读项目，而不是直接改项目。
- 把测试命令、目录边界、发布步骤写进上下文。
- 让每一次修改都有 diff、验证命令和回滚路径。
- 把重复任务沉淀成 Skills 或固定提示。

## 四种入口

| 入口 | 适合场景 | 注意事项 |
| --- | --- | --- |
| Codex App | 日常本地项目、多线程、桌面工作流 | 适合搭配浏览器验收和本地仓库 |
| Codex CLI | 终端用户、脚本化任务、远程环境 | 需要更清楚地管理权限和目录 |
| IDE / Extension | 写代码时的局部辅助 | 适合小范围编辑，不适合长链路发布 |
| Web / Cloud | Issue、PR、云端任务 | 注意仓库权限和敏感信息边界 |

## 第一个 30 分钟练习

1. 打开一个无敏感信息的小项目。
2. 让 Codex 只读扫描项目结构，并总结入口文件、构建命令和风险。
3. 新建或更新 `AGENTS.md`，写入测试命令和禁止触碰的目录。
4. 让 Codex 完成一个小改动，例如更新 README 或修一个 UI 文案。
5. 要求 Codex 运行构建或测试，并解释 diff。
6. 人工 review 后再提交。

## 什么不该交给 Codex

- 未脱敏的客户数据、私钥、cookie、生产数据库密码。
- 没有回滚方案的生产发布。
- 需要你本人最终确认的账号发布、支付、法律或投资决策。

下一步：把你的项目上下文写进 `AGENTS.md`，让 Codex 不是“猜”，而是按你的规则行动。
