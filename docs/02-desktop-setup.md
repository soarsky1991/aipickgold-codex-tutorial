# 用 Codex App 建立第一个工作区

桌面端适合中文用户把本地仓库、浏览器预览、GitHub、Linear 和设计工具放进同一个工作流。

## 第一次打开先做什么

1. 选择一个没有生产密钥的小项目作为练习仓库。
2. 确认 Codex 能看到 README、package.json、测试命令和主要源码目录。
3. 先要求只读总结项目，不要立刻改文件。
4. 把常用命令和禁止触碰的目录写入 AGENTS.md。

## 本地、Worktree、Cloud 怎么选

| 模式 | 适合场景 | 注意事项 |
| --- | --- | --- |
| Local | 本地预览、调试、浏览器验收 | 保持工作区干净，改动前看 diff |
| Worktree | 多任务并行 | 每条线独立提交，避免互相污染 |
| Cloud | Issue 到 PR 的远程执行 | 先确认仓库权限和敏感信息边界 |

## 练习提示词

```text
请用只读方式扫描当前项目，列出入口文件、启动命令、构建命令和潜在风险。
然后提出 3 个适合新手练习的小任务，不要修改文件。
```
