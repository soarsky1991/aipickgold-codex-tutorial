# 站点路线图

AI PickGold Codex 学习站采用系统化课程结构，并加入自己的产品化改造：

- 子域名：`https://codex.aipickgold.com`
- 主站入口：`https://aipickgold.com` 增加 Codex 学习入口
- GitHub 仓库：`soarsky1991/aipickgold-codex-tutorial`
- 内容形态：教程、来源雷达、实战清单、创作者工作流

## 本站创新点

1. 来源雷达：每个仓库展示 license、星标、更新时间和复用方式。
2. 创作者工作流：把 Codex 教程连接到公众号、小红书、视频脚本和发布包。
3. 安全边界：把密钥、账号发布、生产部署写成明确门禁。
4. 双入口学习：开发者路线和内容创作者路线并行。
5. 可执行清单：每章结尾给出 Codex 可直接执行的任务模板。
