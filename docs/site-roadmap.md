# AI PickGold Codex 站点路线图

我是智辰老师。这个站点的目标不是做一个资料壳子，而是把 Codex 学习、个人 IP 内容生产和公开仓库沉淀连成一条路线。

- 子域名：`https://codex.aipickgold.com`
- GitHub 仓库：`soarsky1991/aipickgold-codex-tutorial`
- 公开入口：`Codex` 和 `Founder IP`
- 内容形态：教程、课程地图、实战清单、公开仓库、找我学习入口

## 本站特色

1. **课程化**：12 部分、60 小节，从 Codex App 到 CLI、Cloud、Skills、MCP、GitHub 自动化。
2. **实战化**：每章都尽量落到任务模板、检查清单、构建验证或发布包。
3. **个人 IP 化**：用真实照片、封面、视频和公开仓库证明我不是只讲概念。
4. **安全边界清楚**：公开内容、账号、密钥、部署、生产环境都有边界。
5. **可持续更新**：仓库、网站、小红书、学习群可以形成持续学习闭环。

## 第一阶段

- 网站首页：Codex 是什么、为什么学、课程目录、公开仓库雷达。
- Founder IP：智辰老师介绍、真实照片、视频资产、公开仓库、学习入口。
- 教程仓库：中英 README、课程地图、核心章节、个人 IP 图片。
- 移动端：390px 无横向溢出，首屏能看到品牌、主张和开始学习按钮。
